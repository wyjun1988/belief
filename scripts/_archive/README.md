# 보관 스크립트

여기 있는 것은 **결과가 이미 문서로 확정된 초기 실험**의 산물이다. 셋 다 만족해
옮겼다: (a) 다른 스크립트가 import 하지 않음 (b) 현행 문서가 인용하지 않음
(c) 2026-08-16 이전 마지막 수정.

지우지 않고 남긴 이유: 초기 결과(RESULTS_P0/ABLATION/SCENEGRAPH_20260814,
RESULTS_DEVICEFREE_20260814)의 재현 경로이기 때문이다. 그 문서들의 수치를
다시 확인할 일이 있으면 여기서 꺼내 쓴다.

**현행 파이프라인은 이 파일들에 의존하지 않는다.**
