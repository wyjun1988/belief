- **torchvision 없음** → `AutoVideoProcessor` 불가

⚠️ **외장 SSD 는 TCC(전체 디스크 접근)를 잃으면 통째로 막힌다.** 증상이 특이하다 —
`os.path.exists`·`getsize` 는 되는데 `open()` 이 `PermissionError` 다. 세션 재시작 후
한 번 겪었다. 시스템 설정 → 개인정보 보호 및 보안 → **전체 디스크 접근**에서
터미널(및 `/bin/bash`)을 확인한다.

```

  HostName 10.10.10.10
  User wooyeol
```

→ `ssh mbp` · `rsync -a <경로> mbp:khronos/...` 로 쓴다.
종전 Wi-Fi(192.168.219.123)보다 훨씬 빠르니 **대용량 전송은 반드시 이쪽**으로.

⚠️ 새 주소라 처음 접속 시 호스트 키 등록이 필요했다:
`ssh-keyscan -H 10.10.10.10 >> ~/.ssh/known_hosts`

## 원격 다운로드 주의

**브리스톨 서버(HD-EPIC)가 매우 느리다** — 17.5 GB 를 병렬 4~10개로 받아도 몇 시간이
걸렸다. 평가와 대역폭을 나눠 쓰면 둘 다 느려지므로, 급하면 **다운로드를 잠시 멈추고**
(`pkill -f "curl.*P03"`) 평가를 먼저 끝내는 편이 낫다. `-C -` 로 이어받기가 된다.
