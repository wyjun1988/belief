## 기준선 대비 판정

| 기술 | 기준선을 넘었나 | 근거 |
|---|---|---|
| Pose · Depth · 지도합체 | **해당 없음** (기준선이 자기 이전 값) | 개선폭으로만 판단 |
| Segmentation | **동률** | 0.971 vs GT 0.966 — 차이가 표본 해상도 미만 |
| 물체 존재판정 | **넘음** | F1 1.7배, 두 시퀀스 재현 |
| 기억 검색 | **미확정** | 진짜 상한이 측정된 바 없음 |
| 부재 증거 | **넘음 (유의)** | p=0.014, 단 n=5~8 |
| Belief 세션간 | **넘음** | 최빈방 +20% |
| Belief 가구 | **못 넘음** | 최빈가구 0.24 > 0.15 |
| Belief 방 | **못 넘음** | 최빈방 0.69 > 0.46 |

**기준선을 명확히 넘은 것은 셋이다**: 물체 존재판정 · 부재 증거 · 세션간 belief.

## QA (응답층) — 진행 중, 참고용

| 조건 | 4B | 9B | 비고 |
|---|---|---|---|
| 검색 프레임 (표적 스킬 30문항) | 0.43 | 0.37 | **4B 의 0.43 은 실력 아님** — 응답 30/30 이 A 인데 정답 A 가 43% |
| 검색 프레임 (40문항) | — | **0.47** | 물체위치 0.50 |
| **오라클 프레임** (정답 근거 직접 제공) | **0.50** | **0.50** | **천장이 같다** — 완벽한 검색으로도 절반 |
| 최고 logprob | −3.79 | **−1.77** | 확신 **7배** 차이. 9B 만 정답분포(13/9/8)를 재현(15/11/4) |

무작위 0.33. **표본 30~40문항으로 작다.**

⚠️ 이 층에서 오늘 결함 4건을 찾아 고쳤다 — 검색 풀 붕괴(최근성 τ 기본 ON),
이미지 미처리(`--image-min-tokens 1024`, n_tokens 550→2,212), 프롬프트–문법 모순,
위치 편향(`--rotate` 순환평균 · `--logprob` 직접비교). **이전 QA 수치(0.62·0.47)는
이 결함들 아래에서 나온 값이다.**
