## 기준선 대비 판정

| 기술 | 기준선을 넘었나 | 근거 |
|---|---|---|
| Pose · Depth · 지도합체 | **해당 없음** (기준선이 자기 이전 값) | 개선폭으로만 판단 |
| Segmentation | **동률** | 0.971 vs GT 0.966 — 차이가 표본 해상도 미만 |
| 물체 존재판정 | **넘음** | F1 1.7배, 두 시퀀스 재현 |
| 기억 검색 | **미확정** | 진짜 상한이 측정된 바 없음 |
| 부재 증거 | **못 넘음(막힘)** | 0.761 은 채점 결함 · 바로잡으면 0.49~0.50. 지각층 존재/부재 AUC **0.506** 이 상한 |
| **Belief 방(벽 있는 집)** | **넘음** | 최빈방 +20% — belief 주 경로 |
| Belief 가구 | **보류** | 최빈가구 0.24 > 0.15 · 방 단위로 통일(2026-08-20) |
| Belief 방(개방형) | **못 넘음** | 최빈방 0.69 > 0.46 — 공간 탓 |

**기준선을 명확히 넘은 것은 둘이다**: 물체 존재판정 · **방 단위 belief**(벽 있는 집).

| 최고 logprob | −3.79 | **−1.77** | 확신 **7배** 차이. 9B 만 정답분포(13/9/8)를 재현(15/11/4) |

⚠️ 이 층에서 오늘 결함 4건을 찾아 고쳤다 — 검색 풀 붕괴(최근성 τ 기본 ON),
이미지 미처리(`--image-min-tokens 1024`, n_tokens 550→2,212), 프롬프트–문법 모순,
위치 편향(`--rotate` 순환평균 · `--logprob` 직접비교). **이전 QA 수치(0.62·0.47)는
