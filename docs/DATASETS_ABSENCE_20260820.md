# 부재 증거용 데이터셋 조사 — 2026-08-20

우리 부재 증거가 ADT 에서 우연 수준(AUC 0.49~0.58)에 그친 뒤, 데이터셋 자체가
과제에 맞는지 조사했다. 결론부터: **부재 GT 는 세 종류로 갈리고, 이걸 구분하지
않으면 데이터셋 선택을 틀린다.**

| 유형 | 의미 | 대표 |
|---|---|---|
| **(A) 물체별 시간구간 위치** | "물체 i 가 위치 L 에 t1~t2 동안 있었다" → **부재가 직접 유도됨** | **HD-EPIC · IT3DEgo · ADT** |
| (B) 세션 간 전/후 스냅샷 | "스캔 A 엔 있고 B 엔 없다" → 부재는 있으나 **시점이 없음** | 3RScan · NymeriaPlus · ObChange |
| (C) 프레임별 가시성 | "이 프레임에 안 보인다" → **시야 부재이지 장소 부재가 아님** | Ego4D VQ · EgoTracks · Ego-Exo4D |

우리 과제("원래 있던 자리에 지금 없다")는 **(A) 만 해당**한다. ADT 도 (A) 인데
시퀀스가 짧고(평균 ~2분) 물건이 여러 번 옮겨져 전/후 구분이 어려웠다.


## 결론 (두 조사를 합친 최종 판단 — 2026-08-20)

아래 두 절은 **각각 독립으로 조사돼 서로 다른 1순위를 냈다.** 기준이 달랐다:
1차는 "우리 파이프라인(Aria)에 바로 꽂히는 원자료", 2차는 "부재 라벨이 이미 붙어
있는 것". 우리 상황에서는 **2차 기준이 옳다** — ⑬ 에서 확인했듯 지금 막힌 곳은
데이터 형식이 아니라 **부재를 잴 라벨 자체가 없다**는 것이기 때문이다.

| | 채택 | 이유 |
|---|---|---|
| **먼저 받을 것** | **SceneDiff SD-K** | 객체별 `Removed` 라벨 + 프레임 마스크가 **이미 붙어 있다.** MIT · 11.9GB · 게이트 없음. HD-EPIC 유래라 에고센트릭 조건도 만족 |
| 다음 | **HD-EPIC** | SD-K 의 원본. 19.9K 이동 트랙으로 **시각까지 있는** (A)형이 필요해지면 여기로 간다. 단 115.5GB · CC BY-NC |
| 쓰지 않음 | 3RScan 파생 라벨 | 아래 함정 참조 — 파생 6,515 vs 공식 542 |

⚠️ **단 SD-K 로도 ⑬ 의 근본 문제는 안 풀린다.** 지각층이 존재/부재를 못 가르는 것
(AUC 0.506)이 상한이므로, 데이터셋을 바꾸기 전에 **트랙 ID 기반 인스턴스 식별**이
먼저다. SD-K 의 **인스턴스 마스크가 바로 그 선결 조건을 제공한다** — 이것이
SD-K 를 고르는 두 번째 이유다.

## 1차 조사 — (A) 유형 비교

| | HD-EPIC | IT3DEgo | ADT (현행) |
|---|---|---|---|
| 주석 형식 | `time_segment` + `fixture` + `3d_location` | `(인스턴스, 시작, 종료, xyz, **location_id**)` | per-frame 6DoF |
| 이동 이벤트 | **19.9K tracks** | 인스턴스당 평균 3개 위치 | 74 dynamic 인스턴스 |
| 길이 | 평균 **15.9분** × 156편, 최소 3일 연속 | >5분 × 50 recordings | 평균 **~2분** |
| 환경 | 9 kitchens | **10 실내 씬**(kitchen/garage/office/labs) | 씬 2개 |
| 주석 빈도 | 마스크 단위 | **6 fps** | per-frame |
| 라이선스 | **CC BY 4.0** (NC 아님) | **MIT** | 비상업 |
| 다운로드 | **선택적** — 영상 115.5GB + 디지털트윈 1.35GB | **900GB 단일 링크, 부분 불가** | — |
| 파이프라인 | **Project Aria (VRS+MPS)** — 우리 코드 그대로 | HoloLens2 — 재작성 필요 | Aria |

**(1차 조사 기준) HD-EPIC** — `time_segment`+`fixture` 조합으로 "물체 O 가 시각 t 에 fixture A 를
떠났다"가 직접 유도된다. 6DoF 후처리로 이동을 추론할 필요가 없다. 결정적으로
**Project Aria 촬영이라 우리 파이프라인이 거의 그대로 재사용된다.**
⚠️ 이동의 **27.6% 가 10cm 이하** 미세 이동 — "제자리 밀림 vs 치워짐"을 거리
임계로 분리하지 않으면 신호가 오염된다. 환경은 주방 9개로 다양성이 낮다.

**(1차 조사 기준) IT3DEgo** — `location_id` 가 **우리가 겪은 정확한 약점**(여러 번 옮겨져
전/후 구분이 어려움)을 해소한다. 물체가 평균 3개 위치를 거치되 어느 위치인지가
ID 로 명시된다. MIT 라이선스. ⚠️ 900GB 부분 다운로드 불가, 같은 씬이라도
**시퀀스마다 좌표계가 다르다**(크로스 시퀀스 불가).

**3순위 NymeriaPlus** — 47개 실제 가정집 × 15분. 규모는 압도적이나 **(B) 유형**이라
문제를 "cross-recording absence" 로 재정의해야 하고, 박스 제거 사유가
*"no longer present **or not observed**"* 로 **실제 부재와 미관측을 구분하지 않는다.**

## 2차 조사 — 부재 라벨이 이미 붙은 것 (채택 근거)

3D 스캔·변화 탐지 계열을 별도로 조사해 **egocentric + 객체별 removed 라벨**을
모두 갖춘 데이터셋을 찾았다.

| 순위 | 데이터셋 | 왜 | 라이선스 |
|---|---|---|---|
| **1** | **SceneDiff SD-K** | **HD-EPIC 유래 egocentric 150쌍**. 객체별 **`Added`/`Removed`/`Moved`** 명시 라벨 + 보이는 모든 프레임 인스턴스 마스크(RLE). 350쌍/50씬/1,009객체 | **MIT · 게이트 없음 · 11.9GB** |
| **2** | **HD-EPIC** | Aria 착용 41h/4.4M 프레임, 19.9K 이동 트랙(from→to 시각·3D 위치) | CC BY-NC 4.0 |
| **3** | **ChangeSim** | 프레임별 **`missing`** 독립 클래스, ~130k 프레임 | **MIT · 게이트 없음 · 156GB** |
| **4** | RoomR + `DisableObject` 확장 | 유일하게 walkthrough/unshuffle **2-phase 프로토콜 내장** + 인덱스 정렬 GT. REMOVED 만 없는데 API 로 자작 가능 | **Apache-2.0 · 무제한 생성** |
| **5** | 3RScan | 실사 재스캔의 유일한 큐레이션 `removed` GT — **단 542건뿐** | 커스텀 ToU |

**SD-K 가 1순위인 이유**: 우리가 필요한 세 가지(에고센트릭 · 객체별 removed ·
프레임 마스크)를 모두 갖춘 유일한 공개 데이터셋이고, **MIT 에 11.9GB 로 즉시
받을 수 있다.** `wget https://huggingface.co/datasets/yuqun/SceneDiff/resolve/main/scenediff_benchmark.zip`

### ⚠️ 3RScan 을 쓸 때의 함정 (조사에서 직접 집계로 확인)

"instance ID 가 사라졌으면 제거"로 라벨을 만들면 **안 된다**:

```
reference 에 있고 rescan 에 없는 ID  = 6,515건
공식 removed 리스트                =   542건
두 집합이 정확히 일치하는 rescan   =  170/903 (18.8%)
```

파생-부재 상위가 `wall 592 · ceiling 199 · window 138` — 물리적 제거가 아니라
**미관측**이다. rescan 이 reference 보다 평균 16% 작다.

## ⭐ 재다운로드 없이 당장 가능한 개선

**ADT 아파트 시퀀스들은 동일한 Scene frame `F_S` 를 공유한다**(ADT 논문 3.2절:
서로 다른 시각에 촬영한 여러 캡처의 물체·기기·사람 자세를 같은 좌표계에 그린다).

→ 시퀀스 **내부**의 반복 이동을 보는 대신 **시퀀스 A 의 시작 위치 vs 시퀀스 B 의
시작 위치**를 비교하면, "여러 번 옮겨져 전/후 구분이 어렵다"는 문제 없이
**깨끗한 단일 전이 쌍**이 나온다. 이미 받은 6시퀀스로 즉시 검증 가능하다.

## 확인 안 됨 (추측 금지 항목)

- NymeriaPlus 라이선스 — 사이트 CC BY-NC 4.0 vs arXiv CC BY-NC-SA 4.0 불일치
