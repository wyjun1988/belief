# 새 시뮬레이터 개선 요청 — 실험 근거 정리 (2026-09-10)

대상: AIUE vol8 두 집(01·02) × 4세션(01_unchanged·02_relocated·03_absent·11_scan) = 6채 실행 결과(`docs/NEWSIM_20260909.md`).
**되는 것부터**: 형식·좌표·방 상자·프레임별 GT 는 우리 파이프라인에 그대로 들어간다. 임베딩 카메라방 GT 일치 0.87(HSSD 0.81), 스캔 포즈 지도 재투영 1.6 px, 라이브 PnP 등록 68%, ③ 인계 경로 동작(camera 1/1). 아래는 **성능을 읽을 수 있게** 만들기 위한 요청이다. 순서 = 효과 순.

## 1. 렌더 품질 (① 손실의 절반)
| 근거 | 값 |
|---|---|
| 프레임 평균 밝기 (0~255) | **184** (HSSD 49) — 흰 벽·바닥 과노출 |
| 고주파 잡음 (라플라시안 중앙) | HSSD 의 **5배** — 표면에 점 잡음(디더링 같은 알갱이) |
| OWLv2 재현율 작은/중간/**큰** | 0.23 / 0.38 / **0.20** (OmniGibson 0.52 / 0.61 / 0.66) |
| 초기맵: 타겟 1 m 안에 인스턴스 없음 | **51%** (HSSD 21%) |

큰 물체를 20% 밖에 못 잡는다 = 검출기 문제가 아니라 화면 문제. 요청: **(a) 노출 고정**(자동 노출 상한 또는 고정 EV), **(b) 디노이저/TAA 가 수렴한 뒤 캡처**(1 fps 캡처라도 프레임당 몇 틱 정착), **(c) 해상도 720×540 → 1280×960 이상**. 이 셋만 바뀌면 나머지 항목 없이도 ① 이 크게 움직일 것으로 본다(재현율 0.20 → 0.6 대면 초기맵 누락 절반 해소).

## 2. 증거 물체는 집 안에서 **타입 유일**해야 한다 (②③ 4건 중 3건 무효)
| 세션 | 물체 | 같은 타입 수 | 우리 질의 |
|---|---|---|---|
| 01_02 relocated | mug_5 | **17** | 제외 |
| 01_03 absent | camera_14 | 1 | ✅ |
| 02_02 relocated | book_I4 | **28** | 제외 |

"where is the mug" 는 머그가 17개면 답이 없다. 요청: 증거 물체를 **집 안에서 그 범주가 하나뿐인 것**에서 고른다(camera·headphones·laptop·kettle·toaster 류). 인스턴스 질의("파란 머그")로 넓히려면 인스턴스 속성(색·크기·별칭)을 evidence 에 같이 준다.

## 3. 물체 범주(category) 필드
`class` 가 자산명(`AI62_005_book_I4`, `am245_20_wood_17`, `ai vol7 figure 3`)이라 명사만 남기는 휴리스틱을 썼는데 `fks`·`black plastic`·`water`·`glove`·`tile cooker`·`wood` 같은 것이 남고, 이들이 ① 오답에 몰려 있다. 검출기(OWLv2)는 텍스트 질의를 쓰므로 **깨끗한 영어 범주 한 단어~두 단어**(mug, table lamp, coffee maker)가 있어야 한다. 요청: scene_graph.objects 와 entities 에 `category` 필드 추가(가능하면 우리 어휘 목록과 맞춤 — `data/hssd_move.json` 의 타입 목록 참고).

## 4. 집당 이동 수 (통계가 안 나온다)
지금 집 2채 × 세션 3 = ② 2건·③ 2건. HSSD v2 는 133채·이동 188건이다. 요청: **세션당 이동 여러 건**(②③ 를 한 세션에 섞어도 우리 평가기는 처리) 또는 집 수 확대. 최소 ③ 30건은 있어야 인계율의 오차가 ±0.1 안에 든다.

## 5. 이동 시각 명시
evidence 에 `leave_time_s`·`arrive_time_s` 를 적어 달라. 지금은 관계 변화(`in <room>` 제거/추가)로 복원하는데, 02_03 magazine 은 떠남=도착=111 s 로 운반 구간이 없다(순간이동으로 보임). 운반 장면(사람이 들고 이동)이 있어야 ② 의 "재목격"과 ③ 의 "부재"가 자연스럽다.

## 6. 방 라벨 통일
`bed_room` vs `bedroom`, `Balcony1/2` 처럼 집마다 표기가 다르다. 요청: `snake_case 유형` + 인스턴스 번호(`bedroom`, `bedroom.001`) 로 통일. 방 상자(rect_xy)는 그대로 좋다.

## 7. 파일·메타 정합
- vol8_02 스캔 mp4 의 실제 디코딩 프레임 7,335 ≠ 메타 9,000(annotations 9,000줄). 프레임 인덱스 = 디코딩 순서라면 잘린 원인을 확인해 달라(우리는 추출 장수로 잘라 씀).
- `agent`·mover 캐릭터가 objects 에 섞여 있다 → `is_agent` 표시 또는 제외.
- scene_graph.json 은 map 당 한 벌이면 충분(세션마다 동일).
- depth_mm·instance_mask 는 무GT 실행에 필요 없다(진단용 거리 GT 사다리에만). 당장은 안 받아도 된다.
