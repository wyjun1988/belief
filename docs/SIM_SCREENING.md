# 포토리얼 시뮬레이터 심사 대장 (2026-09-01)

THOR 의 확정 한계는 **렌더 하나**다(원거리 검증 AUC 0.52 vs 실사 0.897 — §101/119).
따라서 대체 심사의 **입장 시험도 그것 하나**: 후보에서 §101 방식 그대로
캘리브레이션 쌍(근/원거리 크롭) 400개 → VLM 로짓 AUC.
**통과선: 5m+ 버킷 AUC ≥ 0.70 그리고 전체 ≥ 0.85** (THOR 는 0.52/0.78 로 탈락값).

## 필수 조건 (3경우 제조)

S1 다방(4~8) 주거 장면 다수(30채+) · S2 물체 이동을 스크립트로(에피소드 중)
S3 프레임 GT(가시성·포즈·인스턴스) · S4 연속 1인칭 궤적 · S5 헤드리스 Linux 렌더

## 진행 절차 (사전등록)

1. **OmniGibson 입장 시험** (RTX 노드): 설치 → 5~10채에서 배회 렌더 수백 장 +
   인스턴스 GT → make_sim_pairs 상당 쌍 400개 → exp_vlm_verify3 → 버킷 AUC.
   통과 시: gen2 상당의 에피소드 생성기 포팅(배회·이동·case3 — 문/수납 활용).
2. 실패·차질 시 SPEAR 로 같은 시험. Habitat 은 렌더 시험만 저비용 선행 가능.
3. 어느 쪽이든 **새 시뮬(1차 타겟)의 대체가 아니라 가교** — 포즈·검증 축을
   포토리얼에서 미리 검증하는 용도. 결과는 이 대장에 추가 기록.
