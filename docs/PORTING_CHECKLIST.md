# 새 도메인 이식 체크리스트 (반복 실수 방지)

같은 실수가 세 번 반복돼 만든다 (2026-09-01 사용자 지적). 새 시뮬·데이터셋을
붙일 때 **아래를 순서대로 확인**하고, 통과 못 하면 수치를 보고하지 않는다.

## A. GT 누출 (가장 자주 반복)

- [ ] `SG_INIT=hybrid` 로 돌렸는가? (기본값 `gt` 는 **초기 씬그래프가 정답**이라
      ① 정답률 0.99 가 자명하게 나온다 — 능력이 아니다)
- [ ] 초기맵(`initmap_owl.json`)을 **검출로 구축**했는가? (`build_initmap.py`)
- [ ] 평가에 쓰는 GT 목록을 적었는가? (거리·포즈·방폴리곤 등 — 사다리 어느 칸인지)

## B. "보이는 방 ≠ 있는 방" (§106)

- [ ] 물체의 방을 **프레임이 찍힌 방**으로 정하고 있지 않은가? 문 너머 물체가
      그대로 오염된다. 질의 국소화(loc_of)뿐 아니라 **초기맵 구축에도** 적용된다.
- [ ] 투영(방위+거리→지도→폴리곤)을 썼는가? `INITMAP_GEO=1`, `LOC_GEO=1`

## C. 좌표 규약 (§120)

- [ ] **앵커 역산 yaw vs 기록 yaw 오차 = 0°** 를 확인했는가? 이 한 줄이 규약을 닫는다.
- [ ] 손잡이(handedness): 화면 오른쪽이 방위각 증가인가 감소인가?
      habitat 은 감소 → x 미러 + yaw 부호 반전 필요.

## D. GT 정직성 (§121)

- [ ] 이동 목적지를 **실제 좌표로 재판정**했는가? (`navigable_point_near` 는 옆방으로
      넘어간다 — 31% 오염 실측)
- [ ] 매핑워크가 **집 전체를 도는가**? 아니면 이동 물체가 exemplar 를 못 가져
      평가 타겟에서 통째로 빠진다.
- [ ] 가시성(vis) 이 거리로 잘려 있지 않은가? (§58 vis-dist)

## E. 표본 성립

- [ ] 경우②·③ 표본 수를 먼저 세었는가? (n<10 이면 판정 불가로 표기)
- [ ] 타입 단일 타겟이 존재하는 채가 몇인가? (실제 주거는 중복이 많다)
