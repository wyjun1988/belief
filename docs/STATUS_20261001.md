## 3. 고친 버그 (모두 "다른 조건에서 만든 파일이 섞인" 한 종류)

| 무엇 | 영향 |
|---|---|
| 새 시뮬에서 **예시 캐시가 없으면 채택 기하가 통째로 꺼졌다** | 4·5차분 ② 채택이 0건이던 원인. 고치니 ② 0.33→0.50 · 0.28→0.44 |
| 채택 필터가 **마진 없는 프레임을 판정기 없이 통과**시켰다 | HSSD 116장 · c2set 은 더 커서 기준선이 ① 0.750→0.784 · ② 0.411→0.430 으로 눌려 있었다 |
| 추론 묶음을 **옛 행 덤프**로 만들어 질의의 1/3만 덮었다 | c2set OR 규칙 판정을 한 번 잘못 내렸다(되돌림) |
| 초기맵 재생성 실험에 **대조군을 같은 실행에서 만들지 않았다** | 별칭 효과가 과장돼 보였다 |
| 요약 줄의 "거짓채택" 이 해로운 채택이 아니었다 | 서술이 과장됐다(결론은 불변) |
| 마진이 상자가 아니라 **프레임**에 걸려 있다 | 이번엔 결과 불변(이득이 기록 선택에서 나옴)이나 관문에서 이득이 나는 변경이면 틀린 결론이 난다 |

함정 12종으로 기록(`khronos-silent-failure-traps`). 대책: 챔피언 구성을 저장소 한 곳에 고정, `--missing drop` 기본화, 묶음 만들 때 덮음률 확인, 요약기 교체.
